# scry 0.1.0-alpha.7

Unreal names, and a much faster attach to large games.

## Unreal `FName`s

Unreal names its levels, classes, gameplay tags and states with `FName`s: a
32-bit index into the engine's name table and a 32-bit instance number, whose
text is not at the address at all. A profile can now read them.

It declares the name table once, at the top:

```json
"fname_pool": {
  "blocks": { "tier": "tier1", "module": "ff7rebirth_.exe", "offsets": ["0x90D3C10"] },
  "entry_align": 4,
  "header_at": 4
}
```

`blocks` is an ordinary base whose chain ends at the pool's `Blocks` array.
`entry_align` (default `2`) and `header_at` (default `0`) are stock Unreal's
layout. Final Fantasy VII Rebirth stores a 4-byte hash before each entry, and so
needs `4` and `4`.

Then `"type": { "string": "fname" }` reads an `FName` anywhere a type goes: a
scalar watch, a record field, a collection element or field. It reads as the
name, or `Name_<n-1>` for an instance number `n` above zero, as Unreal prints
it:

```json
{ "tier": "tier1", "name": "location", "module": "ff7rebirth_.exe",
  "offsets": ["0x8F30420", "0x150", "0x304"], "type": { "string": "fname" } }
```

The table is found at attach and again on every re-attach, like an anchor. An
index that names no entry reads as `unavailable`, never as a neighbour's name.
A profile that reads an `fname` without declaring `fname_pool` is rejected when
it loads.

`FName`s are identifiers, not display text: `0001-WORLD`, not the area's
translated name. An `FString`, Unreal's plain string, needs nothing new; it
reads as `{ "encoding": "utf16", "deref": true }`. `docs/authoring-profiles.md`
covers both, and how to find a game's name table.

## The probe is found in its module first

A profile's probe was scanned for across the whole process in address order. A
64-bit executable is mapped near the top of the address space, above all the
heap, so on a game with gigabytes allocated the scan read all of it before it
reached the module. On Final Fantasy VII Rebirth, `scry watch` took over a
minute to attach.

The scan now starts at the profile's `match.module`, and scans the rest of the
process after it only when the module does not hold the probe. A probe is still
found wherever it is; attaching to that game now takes seconds.

## For code that links the crate

- `StringSpec::layout()` and `StringPreset::layout()` return
  `Option<StringLayout>`: `None` for the new `StringPreset::Fname`.
- `Profile` gains `fname_pool: Option<FNamePool>`. A struct literal needs the new
  field.
- `ValueType::is_fname()` and `aob::find_in_process_from()` are new.
