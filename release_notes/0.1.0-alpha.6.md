# scry 0.1.0-alpha.6

Two additions for profiles of native games, which keep their data in static
tables and compute what the player sees from values nobody else needs.

## Fixed-length collections

A `collection` can now be sized by `len`, a fixed number of elements, instead
of `count`, a chain to a count in memory. A native game's static table stores
no length: one record per character, three party slots in a row. Until now such
a table had to be spelled out as one `record` watch per entry.

```json
{ "tier": "collection", "name": "party_slots",
  "base": { "tier": "tier1", "module": "ff7rebirth_.exe", "offsets": ["0x70D4815"] },
  "len": 3, "stride": 1, "type": "u8", "max": 3 }
```

Set exactly one of `count` and `len`, with `len` at most `max`. A profile that
breaks either rule is rejected when it is loaded, with the watch named. Nothing
is read to size a `len` list, so it has no count that can fail.

Don't use `len` where the game keeps a count. A fixed length over a list that
can shrink reads stale elements past its real end.

## Internal watches

`"emit": false` keeps a watch out of the stream. It is still read on its
schedule, and a derived watch can use it, but its value is never sent, and
`scry schema` leaves it out of the contract. It is for inputs nobody
downstream should depend on: the inventory a gil total is folded from, the
widgets searched for the one on screen.

```json
{ "tier": "collection", "name": "inventory", "emit": false, "…": "…" },
{ "tier": "derived", "name": "gil", "type": "i32",
  "value": { "max": { "watch": "inventory", "field": "qty",
                      "where": [ { "field": "item", "eq": 1 } ] } } }
```

`emit` defaults to `true` and is only written when it is `false`, so existing
profiles load and round-trip unchanged.

## For code that links the crate

- `Watch::Collection.count` is now `Option<Vec<i64>>`, next to a new
  `len: Option<usize>`.
- Every `Watch` variant gains `emit: bool`. A struct literal needs the new
  fields.
- `Session::current()` returns an owned `Snapshot` of the emitted values,
  instead of a reference to the engine's own map, which also holds the internal
  ones.
